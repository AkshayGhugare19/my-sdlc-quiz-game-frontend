CAR models for the Racing game (carBuilder.js, shared by ThreeRaceScene and the
pre-race ThreeCarPreviewScene) — NOT YET SUPPLIED, this is just where to drop one:

  Drop a .glb here named EITHER:
    car-<designId>.glb   — used only for that one CAR_DESIGNS entry (see
                            carBuilder.js), e.g. car-apex.glb, car-titan.glb,
                            car-nimbus.glb, car-ranger.glb, car-classic.glb
    car.glb               — used as the shared default for every design that
                            doesn't have its own car-<designId>.glb
  loadRealCarBody() in carBuilder.js tries the per-design file first, then the
  shared default, then gives up silently — no code change needed either way.

  It replaces ONLY the outer body shell (chassis/cabin/bumpers/skirts/grille/
  scoop/roof-rack/spoiler) — wheels, exhaust flame/smoke, tail light, the
  driver figure, and the name plate are unaffected and stay exactly where they
  are, so garage accessories and the in-race correct/wrong-answer feedback
  (flames, smoke, camera shake) keep working unmodified regardless of which
  body is in use. It's auto-scaled to the procedural chassis length (~3.7
  units) and dropped to sit on the ground — no manual scale/position needed.
  If your model already has its own wheels, tell me and I'll hide the
  procedural ones instead of doubling up.

  Where to get one (free, real-time-game-ready, easy license):
    - Kenney.nl (kenney.nl/assets) — CC0 low-poly car packs; closest match to
      this game's existing style, search "car kit" / "racing kit".
    - Poly Pizza (poly.pizza) — free CC0/CC-BY glTF models, search "car".
    - Sketchfab (sketchfab.com) — filter Downloadable + a CC license, search
      "car" or "sports car"; export/download as glTF/GLB if not already.
  Export as glTF Binary (.glb) with textures embedded (single file, no loose
  .bin/.png beside it) — that's what GLTFLoader expects here.

Character models for the Subway Surfer game (ThreeSubwayScene) — public/models/.

ACTIVE runner (loaded by RUNNER_MODEL_URL in src/game/ThreeSubwayScene.js):

      exported from Adobe Mixamo (https://www.mixamo.com), FBX Binary, With Skin,
      In Place. Loaded via Three's FBXLoader; the single clip is played always,

    - License: Mixamo content is royalty-free for use in personal and commercial

      project owner's own Mixamo (Adobe) account.
    - To change the character: export a new Mixamo character (FBX Binary, With
      Skin, In Place) and replace running.fbx — no code change needed.

ALTERNATE runner (kept as a CC0 option; not loaded unless RUNNER_MODEL_URL points to it):
  runner.glb
    - "RobotExpressive" by Tomás Laulhé (Quaternius), CC0 1.0 (public domain);
      morph targets / cleanup by Don McCurdy. Multi-clip (Idle/Walking/Running/

The loader picks GLTFLoader vs FBXLoader automatically by file extension. If the
model fails to load for any reason, the fully-procedural cel-shaded runner
(buildCharacter in ThreeSubwayScene.js) is used as an automatic fallback.

SCENERY trees (loaded by loadTrees() in ThreeSubwayScene.js):
  All slots are STATIC GLB trees drawn from one weighted pool (via swapTrees()).
  None is pre-animated — a cheap procedural wind-sway (rotation.z on each tree's
  base, own phase/speed) is applied in update() so the roadside still feels alive.
    real_tree_model1.glb — maple; lightest geom (~16k verts), weighted 3× (most common).
    real_tree_model2.glb — euro beech; moderate geom (~29k verts), weighted 2×.
    coconut_palm.glb     — palm; light, weighted 2×.
    mango_tree.glb       — mango; heavy geom (~100k verts), weighted 1× (rare accent).
  All are user-supplied GLB assets (Sketchfab-authored) — verify their original
  source licenses before shipping. If any fails to load, those slots stay
  procedural cones. (Removed earlier: stylized_tree.glb, tree_animate.glb.)

  COMPRESSED with gltf-transform (all decoder-free at runtime: EXT_texture_webp +
  KHR_mesh_quantization, both natively supported by three.js GLTFLoader):
    coconut_palm       12MB  → 1.7MB  (resize 1024 + webp)
    mango_tree         11MB  → 3.2MB  (simplify --ratio 0.28 + webp + quantize; leaf cards resist simplify)
    real_tree_model1  3.3MB  → 0.9MB  (webp + quantize)
    real_tree_model2  5.7MB  → 2.1MB  (webp + quantize)
  Recipes (textures-only):
    npx @gltf-transform/cli resize IN tmp.glb --width 1024 --height 1024
    npx @gltf-transform/cli webp tmp.glb OUT --quality 85
  For high-poly geometry add:  simplify --ratio 0.05 --error 0.05  then  quantize
  If a model uses KHR_materials_pbrSpecularGlossiness (dropped by modern three),
  convert first:  npx @gltf-transform/cli metalrough IN OUT
